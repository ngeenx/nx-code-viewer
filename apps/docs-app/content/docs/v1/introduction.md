# Introduction

Welcome to the **nx-code-viewer** documentation. This site shows you how to
embed a syntax-highlighted code viewer in your application, with native
implementations for Angular, React, Vue, and Svelte.

## What you will find here

- **Documentation** how to install, configure, and theme the code viewer.
- **Examples** runnable cross-framework demos that render the same component
  in your framework of choice.

## Why a documentation site?

The four demo applications under `apps/{angular,react,vue,svelte}-demo` show
each integration in isolation. This docs site stitches them together so the
same component can be compared side by side without juggling four dev servers.
